打开[腾讯云备案控制台](https://console.cloud.tencent.com/beian)，使用服务器所属账号开始办理。备案系统会根据主体和域名的历史记录判断应办理首次备案还是新增服务。

当前服务器地域为 `ap-chengdu`，公网 IP 为 `139.155.149.243`。请选择这台服务器作为备案云资源。服务器计费方式、购买时长和到期时间无法在应用操作系统内确认，应以控制台校验为准。

腾讯云目前要求用于备案的 CVM 或轻量服务器为中国内地有公网 IP 的包年包月实例，累计购买时长不少于3个月，备案期间剩余有效期不少于1个月。若实例不可选，先核对这些条件和登录账号，不要重复购买资源。参考[备案云资源](https://cloud.tencent.com/document/product/243/18908)。

## 备案期间的服务器状态

[腾讯云说明](https://cloud.tencent.com/document/product/243/19637)要求首次备案、新增网站期间关闭网站访问。本项目使用 Caddy 的备案维护模式：

```bash
cd /home/hkb/Projects/wardrowbe
bash deploy/access-mode.sh close
```

该命令将私有配置 `deploy/.env.server` 中的 `SITE_CLOSED_FOR_FILING` 设置为 `true`，并更新入口容器。登录页、图片和公开 API 均返回 HTTP 503，不向外提供应用内容；应用内部健康检查、数据库、上传文件和每日备份继续运行。

域名在腾讯云的外部链路仍可能先被备案系统拦截，因此用户浏览器未必能看到本站的维护提示。服务器内部 HTTP 200 也不能证明公网可用。

## 备案通过后的恢复

1. 确认腾讯云控制台显示备案通过，并取得实际备案号；没有备案号时不要填写示例号或提前开放。
2. 将实际备案号写入服务器私有文件 `deploy/.env.server` 的 `ICP_RECORD_NUMBER`。网站名称如有预审调整，还需同步页面标题与名称。
3. 执行以下命令，让前端加载备案号，再恢复应用入口：

```bash
cd /home/hkb/Projects/wardrowbe
bash deploy/access-mode.sh open
```

未配置备案号时，脚本拒绝恢复。配置后，网页底部显示该号码并链接至 `https://beian.miit.gov.cn/`，不会生成或猜测备案号。参考[备案号展示要求](https://cloud.tencent.com/document/product/243/76865)。

4. 从用户电脑及独立外部网络验证登录页、备案号链接、衣物列表与图片访问；确认 HTTP 不再跳转到腾讯云备案拦截页。
5. 按腾讯云备案完成页面的后续要求完成其余事项。

恢复脚本只能控制本项目的应用入口，不能解除腾讯云的备案拦截。如果控制台已通过但外部链路仍被拦截，应先向腾讯云核实接入状态和同步情况，再进行公网验收。
