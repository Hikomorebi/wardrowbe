# 暂缓备案时的本人私有访问

当前通过服务器公网 IP 连接 SSH，再将服务器本机的衣橱入口转发到自己的电脑。应用端口只绑定 `127.0.0.1`，公开域名入口保持备案维护模式。

## 电脑上的操作

在电脑的 PowerShell、终端或其他支持 OpenSSH 的终端中运行以下命令。应在自己的电脑运行，不是在服务器终端内运行：

```bash
ssh -p 23456 -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:18080:127.0.0.1:18080 hkb@139.155.149.243
```

使用平时登录这台服务器的 SSH 密钥或密码。首次连接时，按正常 SSH 流程核验服务器指纹。连接成功后终端没有输出是正常的，请保持该窗口打开。

然后在电脑浏览器打开：

```text
http://127.0.0.1:18080
```

使用现有衣橱账号登录，邮箱为 `hekunbin@163.com`，密码沿用原来的网页登录密码。SSH 登录凭据和衣橱网页登录凭据是两套不同的凭据。

浏览器到本机转发端口使用 HTTP，电脑到云服务器之间的流量由 SSH 加密。衣物、类别、位置、搭配和图片继续使用原有数据库与文件，不创建另一套衣橱。关闭 SSH 窗口后，这个地址无法继续访问；下次运行同一条命令即可再次连接。

## 服务器设置

启用私有入口：

```bash
cd /home/hkb/Projects/wardrowbe
bash deploy/access-mode.sh private
```

该命令将私有配置设置为：

```text
SITE_CLOSED_FOR_FILING=true
FRONTEND_AUTH_URL=http://127.0.0.1:18080
```

Compose 仅发布 `127.0.0.1:18080:3000`。登录回调使用同一地址，已有账号密码、数据库和备份保持不变。无需在安全组添加应用端口。

## 无法连接时

- SSH 提示认证失败：使用自己正常连接该服务器的 SSH 密钥或密码；不要使用衣橱网页密码。
- 提示本地端口被占用：关闭此前的转发窗口或占用18080的程序；调整端口时需要同步调整登录回调地址。
- 提示转发被拒绝：检查 SSH 服务对该账号的 `AllowTcpForwarding` 和 `PermitOpen` 设置。
- 打不开网页：先确认 SSH 窗口仍在运行，使用 `http://127.0.0.1:18080`，不要改为 `https`，也不要把127.0.0.1替换成服务器公网 IP。

## 日后办理备案

备案资料草稿见 [ICP备案办理](icp-filing.md)。取得真实备案号并确认通过后，配置 `ICP_RECORD_NUMBER` 并运行 `bash deploy/access-mode.sh open`。脚本会先恢复正式 HTTPS 登录地址、加载备案号，再恢复公开入口。此后以 `https://cd.hikomorebi.site` 作为正式访问地址。
